# emu — эмулятор устройства CONTR

Появляется на шаге 2 плана 22: пакет `contr_emu`, `python -m contr_emu` слушает TCP 5025
и исполняет тот же протокол и ту же таблицу блокировок из `gen/relay-numbers.json`
(FW-248…FW-250). Контракт для платформы: `Emulator()` без аргументов,
`supports_nonblocking_poll = True`, `read(timeout_s=0)` без блокировки (FW-249).


Шаг 5: `#button C3 1` нажимает виртуальную кнопку, `#button C3 0` отпускает.
`#advance 100` продвигает время и опрос линий. Директивы принимаются по консоли
и TCP эмулятора; ответ не формируется. `DUT:STAT?` выдаёт MANUAL после подавления
дребезга, сохраняет вмешательство до чтения и показывает PWROK как NA.
Реальная прошивка не принимает эти директивы. Диалог `step5-dut.txt` — только модель.


Шаг 6: PSU:OUTP, PSU:VOLT, PSU:STAT?. DC-OK автоматически появляется через
50 мс после включения RSP. #psu DCOK 0|1|AUTO задаёт вход, #psu ALARM 0|1
задаёт аварию, #psu DAC_FAIL 0|1 имитирует отказ SPI. Эти директивы только
для модели. При аварии RSP выключается без изменения реле/HLG/C* и поколения;
SAFE при зависшем DC-OK возвращает SAFE_INCOMPLETE после 2000 мс.
