# loadboard — прошивка контроллера нагрузок (NUCLEO-G431KB)

Появляется на шаге 7 плана 22: соседнее дерево с тем же делением `hal/` — `core/` — `app/`,
кадр с CRC-8 из общего описания `core/link/frame.c` (FW-245), таймаут связи на аппаратном
таймере, ответ на предыдущий кадр в TX-DMA (FW-189…FW-199). Подмодули
`third_party/cmsis_device_g4` и `third_party/stm32g4xx_hal_driver` уже подключены.
