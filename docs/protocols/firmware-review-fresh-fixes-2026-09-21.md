# Исправления нового независимого ревью — 2026-09-21

Исходный отчёт: firmware-review-fresh-2026-09-21.md. Его содержание сохранено
без изменения выводов; статус исправлений приводится отдельно.

## Подтверждение и изменения

Основной агент повторно запустил uart_repro.exe и cfg_repro.exe, получив
результаты независимого ревьюера. До изменений новые регрессионные проверки
UART, дубликатов и отказа USER падали; после исправления проходят.

1. **UART (P1): исправлено.** При переполнении кольца или ORE/FE/NE приёмник
   передаёт NUL-маркер, который заставляет ядро отклонить повреждённую строку,
   и отбрасывает остаток до LF. Уже накопленные в HAL данные при ошибке теряются:
   сохранение ответов на все команды при переполнении не гарантируется.
   Чтение кольца защищено краткой критической секцией с восстановлением PRIMASK,
   поэтому ISR не сбрасывает head одновременно с чтением основным кодом.
   tests/host/test_target_uart.c включает настоящий target-драйвер и моделирует
   регистры; проверяет исходное переполнение, ORE/FE/NE, ошибку без RXNE,
   восстановление следующей команды и сохранение маски прерываний.
2. **Дубликаты реле (P2): исправлено.** Отдельная маска встреченных реле
   отклоняет повтор до любого GPIO/SR действия. HIGH/LOW/SET и разный регистр
   проверены; состояние, поколение и журнал HAL остаются неизменными.
3. **USER при отказе CFG (P2): исправлена обработка отказа.** Перезагрузка
   вызывается только после успешного сохранения. При отказе добавляются ошибка
   `UPD_SEQ,net defaults: CFG write failed` и запись журнала. Пока кнопку не
   отпустили, новая попытка не производится. Сохранённая конфигурация сохраняется.
4. **Компактация CFG (P2): открыто.** После заполнения запись всё ещё невозможна.
   Исправление USER не восстанавливает доступный объём CFG и не обеспечивает
   FW-229 при полном секторе. Нужен устойчивый протокол резервирования/переноса
   и восстановления после отключения питания, согласованный с обновлением банков.
   Существующее защитное поведение cfg_compact не заменялось стиранием сектора.
