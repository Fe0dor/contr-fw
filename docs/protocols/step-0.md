## Что нужно от разработчика платы

1. Создать репозиторий `Fe0dor/contr-fw` на GitHub (или дать право создать) и принять первый push — после этого CI проверит сборку на Mac.
2. Перепрошить отладчик NUCLEO-F767ZI в J-Link OB, подключить плату CONTR по USB и Ethernet к рабочему компьютеру; сообщить, чем питается плата на столе.
3. Подтвердить список оборудования из раздела 0 плана 22: плата CONTR с NUCLEO-F767ZI, силовик (MUX) с NUCLEO-G431KB, блок нагрузок, два кабеля USB, Ethernet через коммутатор; мультиметр, анализатор или осциллограф на два канала, перемычки и провода с зажимами; блоки питания RSP-2000-48 и HLG — к шагу 6; изделие или имитатор линий — к шагу 5.
4. Назвать COM-порт, под которым виден виртуальный порт J-Link (или дать `python tools/console.py --list`).

## Расхождения с описанием платы

Не выявлены: шаг не трогает сигналы платы. Уточнения раздела «Уточнения» `docs/hardware/contr.md`
учтены в `relays.yaml`: `M7` на `SR0.2.D`, `RAtoDUT`/`RBtoDUT` вместо `RMtoDUT`/`RNtoDUT`,
группы `RA`/`RB` по ТЗ 3.3, `PM*` вне групп.

## Решения шага

- **Подмодули ST** — компонентные репозитории `cmsis_core`, `cmsis_device_f7`, `stm32f7xx_hal_driver`,
  `cmsis_device_g4`, `stm32g4xx_hal_driver` вместо монолитных STM32CubeF7/G4: те же файлы, но без
  сотен мегабайт примеров; клонируются shallow.
- **Стек интерфейса** — tkinter (стандартная библиотека Python) + pyserial: кроссплатформенно,
  без установки платформы, одна команда `python -m contr_ui`.
- **Загрузка** — J-Link Commander по файлу команд (`tools/flash.py`), без pylink: меньше зависимостей,
  одинаково на Mac и Windows.
- **Консоль** — 115200 8N1 (в ТЗ скорость не задана); приём в прерывании в кольцо, логики в
  прерывании нет (А1).
- **Тактирование шага 0** — HSI 16 МГц без PLL; PLL и Ethernet — шаг 1.
