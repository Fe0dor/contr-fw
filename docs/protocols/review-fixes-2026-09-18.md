## Открыто

1. **Устойчивое к потере питания уплотнение CFG.** Нужен версионированный резервный снимок, завершающие маркеры и восстановление при загрузке с учётом TRIAL и совместимости старого образа. Пока при заполнении выдаётся ошибка, данные сохраняются. Требование автоматического уплотнения А10/А11 полностью не выполнено.
2. **Ранний rollback.** Зависание до `upd_boot_check()` не увеличивает счётчик trial. Проверка векторов уменьшает класс ошибок, но не гарантирует исполнение произвольного нового образа. Требуется отдельная доработка стартового пути и проверка восстановления.
3. **SAFE в длительных обработчиках.** Исправлено удержание исполнителя передачей и вытеснение канала. Это не заменяет кооперативную отмену внутри всех будущих длительных операций. Разбор входа всё ещё ограничен очередью; FIFO-ответы не переставляются.
4. Новые исправления проверены на моделях и сборкой; **0.2.5 в рамках этого ревью на плату не прошивалась**. Последнее подтверждённое состояние платы — обычная **0.2.4**, SAFE, `192.168.0.20`, серийный номер UNPROVISIONED; штатный UI был восстановлен ревьюером. Уже работающий сервер UI не перезапускался для загрузки новых исходников.
5. Первоначальное ревью прервано платформенной блокировкой; оно не является исчерпывающим аудитом каждой строки проекта или сторонних библиотек. Ограничения покрытия сохранены в исходном отчёте.

Полная приёмка шагов 1–2 остаётся открытой также по ранее зафиксированным аппаратным измерениям, длительному TCP-простою, альтернативному статическому IP и отсутствующему серийному номеру.
