# Исправления CFG и раннего отката — 2026-09-21

Версия прошивки: 0.4.1. Этот протокол дополняет исторические отчёты ревью,
не изменяя их исходных выводов.

## Изменения

Заполнение 256 записей CFG больше не требует стирания единственной копии.
Последние корректные записи serial/network/trial копируются в отдельный сектор
активного банка. Заголовок и данные защищены CRC; маркер завершения записывается
последним. Только после проверки резервной копии стирается основной сектор.
При следующем старте незавершённый перенос повторяется. При постоянной ошибке
восстановления резервная копия остаётся доступной для чтения, новые записи запрещены.

Основной сектор получает номер поколения с CRC и отдельным маркером завершения.
Резервная копия применяется только к более старому поколению. Это предотвращает
восстановление устаревшей конфигурации при частичном стирании старой резервной копии.
Компактация во время обычной работы разрешена только в безопасном состоянии;
восстановление незавершённого переноса выполняется при старте с отключёнными выходами.

В каждом физическом банке резервируются последние два сектора по 128 КиБ:
резерв CFG по смещению 0xC0000, основной CFG по прежнему смещению 0xE0000.
Журнал по-прежнему занимает первые 16 КиБ основного сектора; формат его записей
не изменён. Максимальный образ уменьшен с 896 до 768 КиБ. Linker и COMMIT
проверяют новый предел. Заголовок обновления содержит маркер CFG2;
0.4.1 отклоняет образы без него, чтобы старый layout не занял резервный сектор.
Геометрия STM32F767 2 МиБ в dual-bank: ST AN4826,
https://www.st.com/resource/en/application_note/dm00266999-stm32f7-series-flash-memory-dual-bank-mode-stmicroelectronics.pdf

Watchdog, восстановление CFG и запись счётчика пробного старта теперь выполняются
до ожиданий тактирования/SPI/I2C. Раннее отключение SR не ждёт SPI.
Чтение remap банка предварительно включает тактирование SYSCFG.
Зависание в последующей инициализации должно приводить к watchdog-reset и откату
при следующем старте. Это не отдельный неизменяемый загрузчик: повреждение
Reset_Handler/SystemInit или зависание до ранней проверки не покрывается.

  65880 байт. Запись `HIL CFG compact 0` подтверждает успешный перенос через
  резервный сектор с реальным стиранием и восстановлением основного CFG.
  Сеть static,.20 и UNPROVISIONED сохранены. Образ подтверждён.
- Затем восстановлена обычная 0.4.1 в банке 1 для использования как резервной.
- Зависание до HAL: образ 4f8896939dd6c9741fa233b8fa7651d822e09176331f774d46c92ff12f5de978,
  45188 байт, с CONTR_HIL_HANG_BEFORE_HAL=ON. Намеренный бесконечный цикл
  расположен после записи trial-счётчика, до sr_start/hal_init, без кормления
  watchdog. Плата вернулась в банк 1: `update: rollback to bank 1`,
  UPD=IDLE, мастер получил подтверждение rolled_back от устройства.
  Весь цикл передачи и наблюдения занял 31 секунду, то есть меньше 60-секундного
  таймаута подтверждения. Точное время watchdog отдельно не измерялось;
  причина последнего сброса software соответствует переключению банка при откате.
- В завершение тестовый образ заменён обычной 0.4.1 с исходным SHA256 выше.
  Она запущена в банке 2 и подтверждена; банк 1 содержит обычную 0.4.1 после
